# Archived Pages

This directory contains templates that are no longer in active use but may be referenced or needed for historical purposes. These pages were archived during a cleanup of the codebase to reduce clutter and improve maintainability.

## Contents

- Backup files (*.bak)
- Older versions of templates
- Unused or duplicate templates
- Templates that have been replaced by newer versions

## Usage

If you need to restore any of these templates, simply move them back to the appropriate templates directory. However, be sure to verify that restoring these templates won't cause conflicts with currently active templates.

## When to Archive

Templates should be archived (moved to this directory) when:

1. They are superseded by newer versions
2. They are no longer used in the application
3. They are kept for reference but not actively used
4. They are duplicates of existing templates with minor variations

## Organization

The archived pages are organized as flat files in this directory. If the number of archived files grows significantly, consider organizing them into subdirectories by category or original location.
