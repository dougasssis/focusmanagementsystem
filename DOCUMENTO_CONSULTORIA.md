# Documento de Apresentação do Projeto

## Projeto
**Focus Management System** é um sistema de gestão para academia de jiu-jitsu, desenvolvido para administrar alunos e filiados, com recursos de controle operacional e acompanhamento da rotina da academia.

## Tecnologias utilizadas
- **Python**
- **Django** (framework principal)
- **SQLite** (base local no projeto)
- **PostgreSQL** (suporte via dependência `psycopg2`)
- **HTML/CSS/JavaScript** (camada web)
